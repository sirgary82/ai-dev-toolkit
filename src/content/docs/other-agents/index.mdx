While the core tracks of this toolkit focus on GitHub Copilot in VS Code and Claude Code in your terminal, the broader ecosystem of agentic coding tools has matured rapidly. Three major terminal agents stand out alongside Claude Code: **OpenAI's Codex CLI**, **Google's Gemini CLI**, and **GitHub's Copilot CLI**.

All four tools share the same agentic foundation: an AI model running inside a local loop that can inspect your codebase, execute terminal commands, run tests, observe output, and iterate autonomously. However, each CLI comes from a different engineering philosophy with distinct architectural trade-offs, pricing models, and killer features.

<Callout type="note">
  The patterns you learn across this toolkit — prompt discipline, scoping tasks, incremental commits, test-driven loops,
  and verification gates — apply directly to all of these tools. The agent loop is universal; only the harness changes.
</Callout>

## The Big Milestone: Unified AGENTS.md Support

For over a year, developers navigating multiple tools faced a frustrating fragmentation problem: Claude Code used `CLAUDE.md`, Gemini CLI preferred `GEMINI.md`, and OpenAI / Cursor championed `AGENTS.md`. Teams were forced either to maintain duplicate context files or write brittle symlinks.

**Today, that friction is gone: Claude Code now natively supports `AGENTS.md` out of the box.**

This long-awaited update unifies context across the entire ecosystem:

```
Your Repository Root
├── AGENTS.md                ← The universal project contract (read by all agents)
│                              - Build & test commands
│                              - Code style & architectural invariants
│                              - Off-limits directories & safety boundaries
```

### How Each Tool Reads AGENTS.md

- **Claude Code:** Reads `AGENTS.md` automatically at session launch. If both `CLAUDE.md` and `AGENTS.md` exist in the same directory, Claude merges both, giving precedence to `CLAUDE.md` for tool-specific settings while respecting `AGENTS.md` for shared project rules.
- **Codex CLI:** Natively parses `AGENTS.md` from the root and across subdirectories, using it to constrain its tool choices and test execution loops.
- **Gemini CLI:** Reads `AGENTS.md` natively as part of its workspace configuration alongside `GEMINI.md`.
- **GitHub Copilot CLI:** Automatically ingests `AGENTS.md` alongside repo-level instruction files in `.github/instructions/`.

By committing a clean, structured `AGENTS.md` to your repository, you provide instant context to every developer on your team, regardless of which terminal agent or AI-enabled IDE they prefer.

Gemini CLI is Google's open-source terminal coding agent (Apache 2.0). It operates directly in your shell, capable of reading directories, running system commands, browsing the web, and completing multi-step coding workflows autonomously.

What sets Gemini CLI apart from other coding agents is its combination of a massive context window, live Google Search grounding, and an exceptionally generous free tier for developers.

---

## "What's the Jam?" — Why Developers Choose Gemini CLI

1. **The 1M+ Token Context Window:** While most models cap effective context between 128k and 200k tokens, Gemini 2.5 Pro can ingest up to 1,000,000+ tokens in a single prompt. You can load an entire monorepo, its documentation, and database schemas into memory without chunking or losing context.
2. **Built-In Google Search Grounding:** Gemini CLI has native access to Google Search. When asked to use a cutting-edge library, a brand-new framework release, or diagnose an obscure error code, it performs live web searches directly to fetch up-to-date documentation rather than relying on stale training weights.
3. **Unbeatable Free Tier:** Using a personal Google account, Gemini CLI provides **60 requests per minute and 1,000 requests per day at zero cost** on the Gemini 2.5 model family. No credit card or paid subscription is required.
4. **Vertex AI Enterprise Compliance:** For enterprise engineering teams with data governance mandates, Gemini CLI switches seamlessly to Google Cloud Vertex AI, honoring VPC Service Controls, private endpoints, and strict data confidentiality guarantees.

## Installation & Setup

### 1. Install the CLI

```bash
# Direct execution via npx (no installation needed)
npx @google/gemini-cli

# Global installation via npm
npm install -g @google/gemini-cli

# Homebrew (macOS / Linux)
brew install gemini-cli
```

### 2. Authentication Options

Gemini CLI supports three authentication pathways:

**A. Google Account OAuth (Recommended for Individuals / Free Tier):**

```bash
gemini
# Follow the terminal prompt to authenticate in your browser.
# Automatically unlocks the 60 req/min, 1,000 req/day free tier.
```

**B. Google AI Studio API Key:**

```bash
export GEMINI_API_KEY="AIzaSy..."
gemini
```

**C. Google Cloud Vertex AI (Enterprise):**

```bash
export GOOGLE_CLOUD_PROJECT="my-enterprise-project"
export GOOGLE_GENAI_USE_VERTEXAI=true
gemini
```

## Quickstart: How to Use Gemini CLI

### 1. Interactive Coding Session

Run `gemini` in your project root to enter the interactive REPL:

```bash
cd my-app
gemini
```

```
╭─────────────────────────────────────────────────────────────╮
│ Google Gemini CLI (v0.5.x)                                  │
│ Model: gemini-2.5-pro | Context: 1M tokens | Free Tier Active │
╰─────────────────────────────────────────────────────────────╯

> Analyze our entire /src directory and find any components that re-render unnecessarily.
```

Gemini CLI will read through your component tree, trace props and state hooks across files, and report a prioritized refactoring list.

### 2. Non-Interactive Scripting (`-p`)

Gemini CLI excels at headless automation in shell scripts and CI jobs using the `-p` (prompt) flag:

```bash
# Summarize git changes since the last release tag
gemini -p "Summarize all changes between v1.4.0 and HEAD in customer-friendly release notes format"

# Structured JSON output for downstream tooling
gemini -p "List all exported endpoints from src/routes in JSON format" --output-format json
```

### 3. Piped Workflows (Unix Philosophy)

Because Gemini CLI respects stdin and stdout, you can pipe file contents and logs directly into it:

```bash
# Pipe crash logs for immediate diagnosis
cat crash.log | gemini -p "Explain why this process crashed and provide the fix for main.go"

# Transform database schemas into TypeScript types
cat schema.sql | gemini -p "Convert this PostgreSQL schema into clean Zod validation schemas" > schemas.ts
```

### 4. Search-Grounded Debugging

When dealing with a new API error or an unreleased library feature, tell Gemini to ground its answer:

```bash
> Why am I getting "TypeError: React.useActionState is not a function"? Verify against current React 19 docs.
```

Gemini CLI will execute a live Google search query in the background, read the official React documentation, and identify that the signature or package import requires the latest canary/release bundle.

## Context Configuration: GEMINI.md & AGENTS.md

Gemini CLI supports both its native `GEMINI.md` format and the universal `AGENTS.md` standard:

```
~/.gemini/GEMINI.md           ← Global instructions for all projects on your machine
my-repo/
├── AGENTS.md                 ← Universal repo conventions (read automatically)
└── GEMINI.md                 ← Gemini-specific instructions & tools (optional)
```

### Example Context File

```markdown
# Project Guidelines (AGENTS.md / GEMINI.md)

## Tech Stack

- Next.js 15 (App Router), TypeScript, Tailwind CSS
- Vitest for unit tests, Playwright for E2E

## Architectural Constraints

- Always use Server Components unless interactive state is strictly required (`'use client'`).
- Validate all incoming route request bodies with Zod.
- Run `npm run test:unit` after making changes to verify correctness.
```

## Configuration & Customization (`settings.json`)

Customize Gemini CLI behavior in `~/.gemini/settings.json` or `.gemini/settings.json` in your workspace:

```json
{
  "model": "gemini-2.5-pro",
  "temperature": 0.2,
  "contextWindow": 1000000,
  "tools": {
    "googleSearch": true,
    "shellExecution": true,
    "fileSystem": true
  },
  "safety": {
    "autoApproveReadOnlyCommands": true,
    "requireApprovalForMutations": true
  }
}
```

## When to Reach for Gemini CLI

- **Massive Codebases & Monorepos:** When your codebase exceeds the 200k token context window of other models and you need holistic understanding without context truncation.
- **Fast-Moving Ecosystems:** When you are working with cutting-edge libraries released recently and need Google Search grounding to fetch live documentation.
- **Budget-Conscious Development:** For hobbyists, open-source contributors, and independent developers who want high-performance frontier model agency without a $20/month subscription.
- **Shell-Scripted Pipelines:** When building automated scripts that pipe data into and out of LLMs on the command line.
